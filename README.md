In this project, I created a multi-router enterprise network simulation using Cisco Packet Tracer to gain practical experience in routing, switching, VLAN configuration, and network troubleshooting.
# Enterprise Network Simulation using Cisco Packet Tracer

## Project Overview

This project demonstrates the implementation of a multi-router enterprise network using Cisco Packet Tracer. The network includes VLAN segmentation, inter-VLAN routing, OSPF dynamic routing, ACL-based security, and network troubleshooting.

## Technologies Used

* Cisco Packet Tracer
* Cisco CLI
* OSPF Routing Protocol
* VLANs & Trunking
* Inter-VLAN Routing
* ACL Security
* TCP/IP Networking

## Network Features

* Configured VLAN 10, 20, 30, and 40
* Implemented trunk links between switches and routers
* Configured router-on-a-stick inter-VLAN routing
* Established OSPF routing between routers
* Applied ACL rules to restrict traffic between VLANs
* Verified connectivity and routing using troubleshooting commands

## Verification & Testing

* Verified OSPF neighbor adjacency
* Verified routing table propagation
* Tested successful end-to-end connectivity
* Tested ACL traffic blocking between VLAN 20 and VLAN 30
